## Platform

## Stack

Static HTML + CSS + vanilla JavaScript, no frameworks, no build step (user requirement).

## Users

- **Clientes potenciales** (negocios en Colombia, en su mayoría pymes B2B) que buscan quien les haga una web o una herramienta y quieren ver trabajo real publicado antes de escribir.
- **Reclutadores y equipos técnicos** que evalúan a Kyle como desarrollador web. Llegan desde LinkedIn, GitHub o un enlace directo, a menudo desde el celular.

## Product Purpose

Portafolio personal de Kyle Navarro como desarrollador web. Éxito = el visitante abre un proyecto real, y luego le escribe un correo, descarga el CV o visita GitHub / LinkedIn.
