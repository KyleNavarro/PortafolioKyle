Sobre mí

Soy un programador inquieto. Antes de escribir código vendía a empresas, y eso me dejó algo que uso todos los días: entender cómo decide un cliente B2B, qué necesita ver para confiar y qué lo hace dar el siguiente paso.

Hoy construyo webs y herramientas para negocios reales: catálogos que terminan en una cotización por WhatsApp, tiendas de pedidos y sitios corporativos. Trabajo con desarrollo asistido por IA para pasar rápido de la idea a algo publicado, sin soltar el criterio sobre lo que se entrega.

Tecnologías

  • TypeScript Tipado estricto en apps grandes, como FlashBuy.
  • Node.js Servidores y APIs, como el de AgentPrice.
  • Tailwind CSS Interfaces consistentes y rápidas de iterar.
  • Claude Code Mi entorno de trabajo diario, desde la terminal.
  • Desarrollo asistido por IA Planear, construir y revisar con IA, con criterio humano en cada entrega.

También uso HTML CSS JavaScript React Vite Supabase
